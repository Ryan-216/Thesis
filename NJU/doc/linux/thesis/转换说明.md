# LaTeX → Word 转换说明

本说明用于将 `thesis_aigc.tex`（njuthesis 研究生模板）转换为格式匹配的 `.docx` 文件。

## 环境依赖

```bash
# 必须的包
sudo apt install pandoc pandoc-citeproc

# Python 依赖
pip3 install python-docx lxml
```

## 转换步骤

### 1. 编译 PDF（生成交叉引用辅助文件）

```bash
cd NJU/doc/linux/thesis
xelatex thesis_aigc.tex
biber thesis_aigc
xelatex thesis_aigc.tex
xelatex thesis_aigc.tex
```

### 2. pandoc 转换（生成带参考文献的 docx）

```bash
cd NJU/doc/linux/thesis
pandoc thesis_aigc.tex \
  --from=latex \
  --to=docx \
  --resource-path=. \
  --bibliography=thesis.bib \
  --filter pandoc-citeproc \
  -o thesis_tmp.docx
```

### 3. 应用南京大学论文格式 + 清理问题

```bash
python3 format_docx.py thesis_tmp.docx thesis_aigc.docx --no-cover --clean-refs
```

然后删除临时文件：
```bash
rm thesis_tmp.docx
```

最终产物：`thesis_aigc.docx`

## format_docx.py 做了什么

| 步骤 | 说明 |
|------|------|
| 页面设置 | A4, 上下 2.54cm, 左右 3.18cm |
| 正文样式 | 小四(12pt), 宋体/Times New Roman, 1.5× 行距 |
| Heading 1 (章) | 小二(18pt), 黑体+Arial, 加粗, 居中 |
| Heading 2 (节) | 小三(15pt), 黑体+Arial, 加粗 |
| Heading 3 (小节) | 四号(14pt), 黑体+Arial, 加粗 |
| 表格 | 五号(10.5pt), 宋体 |
| 清理交叉引用 | `[tab:xxx]` → `【表xxx】`, `[fig:xxx]` → `【图xxx】` |
| 清理重复引用 | `（Author, Year）(Author Year)` → `（Author, Year）` |
| 去除封面 | `--no-cover` 移除 pandoc 无法正确生成的封面页 |

## 参数说明

```
python3 format_docx.py <输入.docx> <输出.docx> [选项]

选项:
  --no-cover    移除封面（封面需从 PDF 截图手动添加）
  --clean-refs  清理交叉引用标签和重复引用
```

## 转换后在 Word 中手动完成的 5 件事

1. **添加封面** — 从 PDF 截图第 1 页粘贴到文档开头
2. **添加声明页** — 从 PDF 截图第 2 页粘贴到封面之后（如启用了 `decl-page`）
3. **生成目录** — 「引用」→「目录」→ 自动目录（Heading 层级已保留）
4. **查找替换** — 搜索 `【表` 和 `【图`，替换为实际表号/图号
5. **添加页眉** — 奇偶页不同，奇数页显示章标题，偶数页显示论文题目

## 已知限制

| 问题 | 原因 | 处理方式 |
|------|------|----------|
| 封面丢失 | njuthesis 类内部生成，pandoc 不认 | 从 PDF 截图手动添加 |
| 引用变成作者-年份 | 原 LaTeX 用脚注引用，pandoc 转为内联 | 格式符合常见期刊要求 |
| 三线表格式偏移 | pandoc 不完全支持 booktabs | 在 Word 中手动微调 |
| 公式交叉引用丢失 | pandoc 不解析 `\eqref` | 手动补充 |
