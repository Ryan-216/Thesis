- **非定向信息披露**

  - 披露内容：捐赠金额、捐赠者（如公开）、时间
  - 受众：广泛的社区成员、公众
  - 频率：不定期，收到捐赠后及时公布
  
- **定向信息披露**
  - 在官网公布资助的开发者信息
  - 披露内容：受资助开发者名单、资助金额、资助期限
  - 受众：社区成员、潜在申请者
  - 频率：定期更新

  - 两次披露存在时间间隔
  - 允许分离信息披露与资金支付的效应
  - 为研究信息披露的独立作用提供自然实验场景

#### 3.2.3 资助对象与金额
- 2020-2023年资助记录统计
- 受资助开发者列表（表格）
- 资助金额范围：年度资助10万-15万美元
- 受资助者占总开发者比例：<5%
- 资助标准：技术能力、贡献历史、项目计划

### 3.3 研究一的理论框架与假设 (2页)

#### 3.3.1 信息披露的激励机制
- 信息作为信号的理论基础
- 预期形成的心理机制
- 为何信息本身具有激励作用
- 在开源场景中的特殊性

#### 3.3.2 期望失验理论的应用
- EDT核心逻辑回顾
- 在信息披露场景中的应用
- 非定向披露→预期形成
- 定向披露→预期确认或失验

#### 3.3.3 研究假设
**假设1a**：非定向捐赠信息披露（X平台公布接收捐赠）正向影响开发者贡献活动。

*理论依据*：非定向信息披露传递积极信号（基金会获得资金支持，项目受到重视），提升开发者对项目前景的预期和对自身获得资助的期望，从而激励其增加贡献以提高被资助的可能性。

**假设1b**：定向捐赠信息披露（官网公布受资助开发者）正向影响开发者贡献活动。

*理论依据*：定向信息披露明确了资助标准和受益者特征，为开发者提供了努力方向和角色模型，激励其向受资助者学习并增加贡献。

**假设1c**：非定向披露与定向披露的交互项负向影响开发者贡献活动。

*理论依据（期望失验理论）*：非定向披露创造了积极预期和模糊的期望（开发者可能期待自己有机会获得资助）。当定向披露公布具体受赠者后，未被选中的开发者意识到预期落空，产生期望失验（失望），削弱了先前非定向披露的激励效应。交互项为负反映了这种削弱效应。

### 3.4 研究二的理论框架与假设 (2页)

#### 3.4.1 情感即信息理论的应用
- **理论核心回顾**
  - Schwarz & Clore (1983, 2003)：情感作为信息
  - 情感为判断和决策提供诊断性信息
  - 情感状态反映当前环境状况

- **在开源场景中的应用逻辑**
  - GitHub Issue中的情感表达反映项目状态
  - 负面情感信号项目存在问题
  - 积极情感信号项目运行良好
  - 情感作为行动的触发信号

- **情感的信号功能**
  - 诊断功能：判断情况严重性
  - 引导功能：指向需要注意的领域
  - 激励功能：驱动问题解决行为

#### 3.4.2 目标-手段替代理论的应用
- **理论核心回顾**
  - Kruglanski et al. (2002)：目标系统理论
  - Zhang et al. (2007)：手段的等价性
  - 多种手段可服务于同一目标

- **在开源场景中的应用**
  - 共同目标：解决项目问题
  - 两种手段：代码修复（直接）vs 讨论协调（间接）
  - 手段选择基于效率和成本

- **手段替代的条件**
  - 功能等价性：代码和讨论都能解决问题
  - 效率差异：代码是更直接的解决方式
  - 替代效应：当代码活动完成目标后，讨论需求下降

#### 3.4.3 链式影响机制
- **情感→行为的链式路径**
  - 阶段一：情感作为信息触发行为（情感即信息理论）
  - 阶段二：行为间的目标替代关系（目标-手段替代理论）

- **理论整合的逻辑**
  - 情感信号问题存在→触发多种应对行为（代码+讨论）
  - 代码活动实现目标→讨论活动需求下降（替代效应）
  - 形成"情感→代码/讨论→讨论"的动态链条

- **机制的独特性**
  - 不同于简单的资源损耗
  - 强调目标实现的功能性替代
  - 行为选择具有目标导向性

#### 3.4.4 研究假设
**假设2a**：社区情感极性负向影响后续代码活动（滞后效应）。

*理论依据（情感即信息理论）*：根据情感即信息理论，情感极性下降（负面情感增加）为开发者提供了项目存在问题的诊断性信息。负面情感作为环境状态的信号，告知开发者需要采取行动。开发者将这一情感信息解读为"项目需要修复"，从而增加代码活动（bug修复、功能改进）来应对问题。因此，情感极性与后续代码活动呈负相关。

**假设2b**：社区情感极性负向影响后续讨论活动（滞后效应）。

*理论依据（情感即信息理论）*：负面情感同样信号需要通过讨论来协调和澄清的问题增多。当情感极性下降时，开发者感知到项目中存在需要沟通解决的矛盾或分歧，从而增加讨论活动（Issue讨论、评论）来达成共识和明确解决方案。

**假设2c**：代码活动负向影响后续讨论活动（滞后效应）。

*理论依据（目标-手段替代理论）*：代码活动和讨论活动都是实现"解决项目问题"这一共同目标的手段。根据目标-手段替代理论，当一种手段（代码修复）成功实现目标后，另一种手段（讨论）的需求自然下降。代码活动作为更直接、更有效的问题解决方式，其完成意味着问题已得到处理，因此降低了进一步讨论的必要性。这是功能性替代，而非简单的资源损耗。

**假设2d**：存在"情感→代码/讨论→讨论"的链式影响路径。

*理论依据（理论整合）*：整合情感即信息理论和目标-手段替代理论，情感作为信息信号触发开发者的问题解决行为（代码和讨论），这两种行为作为实现目标的手段存在替代关系（代码活动完成后，讨论活动需求下降），形成多步骤的影响链条。这一链式机制揭示了情感如何通过行为的功能性替代间接影响后续行为。

### 5.2 VAR模型 (5-6页)

#### 5.2.1 VAR模型设定
**向量自回归（VAR）模型一般形式**：
```
Yt = A1*Yt-1 + A2*Yt-2 + ... + Ap*Yt-p + Ct + εt
```

其中：
- Yt = [Sentiment_t, Coding_t, Discussion_t]'（3×1向量）
- Ai：系数矩阵（3×3）
- p：滞后阶数
- Ct：常数项和外生变量
- εt：随机扰动项（白噪声）

**具体模型**（p=2）：
```
Sentiment_t = α11*Sentiment_t-1 + α12*Coding_t-1 + α13*Discussion_t-1
            + α14*Sentiment_t-2 + α15*Coding_t-2 + α16*Discussion_t-2
            + Controls + ε1t

Coding_t = α21*Sentiment_t-1 + α22*Coding_t-1 + α23*Discussion_t-1
         + α24*Sentiment_t-2 + α25*Coding_t-2 + α26*Discussion_t-2
         + Controls + ε2t

Discussion_t = α31*Sentiment_t-1 + α32*Coding_t-1 + α33*Discussion_t-1
             + α34*Sentiment_t-2 + α35*Coding_t-2 + α36*Discussion_t-2
             + Controls + ε3t
```

#### 5.2.2 格兰杰因果检验
**目的**：检验变量之间的因果先后关系

**方法**：Granger Causality Test
- H0：X不是Y的格兰杰原因
- 检验统计量：F统计量

- 置信区间：Bootstrap方法（1000次抽样）

## 第六章 研究讨论 (10-12页)

### 6.1 主要发现总结 (2页)

#### 6.1.1 研究一的主要发现
**发现1**：非定向捐赠信息披露正向激励开发者贡献
- 非定向披露在X平台公布后，非受赠开发者活动平均增加15-20%
- 效应持续8-12周
- 信号作用：传递项目受重视、资金充足的信息

**发现2**：定向捐赠信息披露正向激励开发者贡献
- 定向披露在官网公布后，非受赠开发者活动平均增加10-15%
- 效应持续6-10周
- 学习作用：明确资助标准，提供努力方向

**发现3**：期望失验效应显著存在
- 两种披露的交互项显著为负（-8%到-12%）
- 定向披露后，非受赠者意识到未被选中，产生失望
- 削弱了先前非定向披露的积极效应
- 期望失验理论在开源场景中得到验证

**理论意义**：
- 信息披露本身具有激励作用（独立于资金支付）
- 不同类型的信息披露产生差异化效应
- 预期管理在开源社区激励中的重要性

#### 6.1.2 研究二的主要发现

- 同时激励开发者增加讨论活动（10-20%）

**发现3**：链式影响机制存在

- 整合AET和自我调节资源理论的框架有效

**理论意义**：

## 第七章 研究结论 (5-6页)

### 7.1 主要研究结论 (2页)

本文以比特币开源社区为研究对象，从外部激励和内部情感两个维度探讨了开发者活动的影响机制。通过两个相互关联的研究，本文得出以下主要结论：

**研究一的核心结论**：
1. **信息披露具有独立的激励作用**：即使不涉及实际资金支付，捐赠信息的披露本身就能激励开发者增加贡献。这一发现拓展了开源激励机制的理解，揭示了信息作为激励手段的价值。

2. **不同类型的信息披露产生差异化效应**：非定向披露（公布捐赠总额）和定向披露（公布具体受赠者）都能正向激励开发者，但机制不同。非定向披露通过信号传递创造积极预期，定向披露通过明确标准提供努力方向。

3. **期望失验机制显著存在**：定向披露后，非受赠开发者产生期望失验（失望），削弱了先前非定向披露的积极效应。这一发现首次将期望失验理论应用于开源场景，强调了预期管理在信息披露中的重要性。

**研究二的核心结论**：
1. **情感对开发者活动具有链式影响**：社区情感不仅直接影响开发者行为，更通过触发一系列行为形成链式反应。情感极性下降（负面情绪增加）信号项目存在问题，激励开发者通过代码修复和讨论参与来应对。

2. **认知资源约束塑造行为权衡**：代码活动作为高认知密集的任务，消耗大量心理资源，导致后续讨论活动减少。这一发现引入自我调节资源理论，揭示了开发者行为受到认知资源有限性的约束。

3. **理论整合有效解释复杂机制**：通过整合情感事件理论和自我调节资源理论，本文构建了"情感→行为→行为"的链式机制框架，为理解开源社区中情感与行为的动态关系提供了新视角。

**综合结论**：
开源社区开发者活动受到外部信息激励和内部情感动态的共同影响。信息披露通过信号传递和预期塑造激励开发者，但需要谨慎管理期望失验效应。社区情感通过链式反应影响开发者的代码和讨论活动，而开发者行为受到认知资源有限性的约束。理解这些多维机制对于促进开源项目的可持续发展至关重要。

   - 构建综合性研究数据集
   - 提供更完整的研究视角

### 7.3 实践应用价值 (1页)

#### 对开源基金会
- 优化信息披露策略，平衡透明度与激励效应
- 管理开发者期望，降低期望失验的负面影响
- 设计多元化激励措施，让更广泛的开发者受益

#### 对开源项目维护者
- 关注社区情感氛围，及时识别和应对负面情感
- 理解负面情感的积极作用，引导其转化为建设性行为
- 合理分配开发任务，考虑开发者的认知资源有限性

#### 对开源赞助方
- 重视信息披露本身的激励价值
- 协商最佳披露方式和时机
- 提供多元化支持，扩大激励覆盖面

#### 对开源生态
- 促进开源项目的可持续发展
- 提升开发者参与度和活跃度
- 为其他开源项目和区块链项目提供参考

### 7.4 政策建议 (1页)

#### 7.4.1 开源基金会的信息披露政策
**建议1**：建立分阶段信息披露机制
- 第一阶段：公布总体资助计划和资金筹集情况
- 第二阶段：预告资助标准和申请流程
- 第三阶段：分批公布受资助者，降低单次冲击

**建议2**：加强预期管理
- 在披露过程中明确资助的竞争性
- 强调未被选中不代表贡献不被认可
- 提供未入选者的反馈和改进建议

**建议3**：多元化激励措施
- 设立不同层级的资助项目
- 提供非资金形式的支持（培训、会议、设备）
- 公开表彰所有重要贡献者

#### 7.4.2 开源社区的情感治理
**建议1**：建立情感监测机制
- 使用情感分析工具定期评估社区氛围
- 设立早期预警系统，识别负面情感积累
- 建立情感健康指标体系

**建议2**：促进建设性情感表达
- 制定社区行为准则，鼓励积极沟通
- 提供结构化讨论渠道（Issue模板、讨论指南）
- 培训核心维护者的情感管理技能

**建议3**：合理管理开发者工作负荷
- 避免同时推进过多高强度任务
- 给开发者恢复精力的缓冲期
- 提供资源支持（如CI/CD工具，减少重复劳动）

### 7.5 研究展望 (1页)

开源软件作为数字经济的重要基础设施，其可持续发展依赖于开发者的持续贡献。理解和优化开发者激励机制是开源研究的核心议题。本文通过聚焦信息披露和社区情感两个关键因素，为这一领域的研究贡献了新的理论视角和实证证据。

**未来研究可从以下几个方向深化**：

1. **拓展研究场景**：将本文的发现推广到更多开源项目，识别通用规律和项目特异性因素。特别关注不同规模、不同领域、不同治理模式的开源项目。

2. **深化机制研究**：通过实验、访谈等方法深入探索信息披露和情感影响的微观心理机制。结合神经科学方法，揭示情感处理和决策制定的认知过程。

3. **整合多维因素**：将信息披露、情感、声誉、企业赞助等多种激励因素整合到统一框架中，研究它们之间的交互作用和协同效应。

4. **技术创新应用**：利用人工智能、大数据分析等新技术，开发实时监测和干预系统，为开源社区提供智能化的治理工具。

5. **跨学科融合**：借鉴心理学、经济学、社会学、管理学等多学科的理论和方法，构建更全面的开源社区研究范式。

开源社区是人类协作创新的典范，也是数字时代新型组织形式的探索。理解其运作机制不仅有助于促进开源软件的发展，更为理解未来的数字协作和组织治理提供了宝贵洞见。期待本文的研究能够抛砖引玉，激发更多学者关注开源社区这一富有研究价值的领域。

## 大纲要点总结

### 强调的研究重点

1. **Bitcoin Brink的特殊研究场景**
   - 两次清晰的信息披露（非定向+定向）
   - 时间差允许分离效应
   - 受资助者占比小，可剔除
   - 数据高度透明

2. **研究信息披露而非捐赠额**
   - 核心：信息本身的激励作用
   - 区分：信息 ≠ 资金
   - 对象：非受赠开发者
   - 理论：期望失验理论

3. **情感的链式影响**
   - 路径：情感→代码/讨论→讨论
   - 阶段一：情感作为信息触发行为（情感即信息理论）
   - 阶段二：行为间的功能性替代（目标-手段替代理论）
   - 整合：多步骤动态机制，强调目标导向的行为选择

### 行文逻辑

- **递进式**：从背景→问题→理论→实证→讨论→结论
- **证据链**：理论假设→实证检验→稳健性→异质性→机制
- **理论整合**：期望失验理论 + 情感即信息理论 + 目标-手段替代理论
- **贡献清晰**：理论贡献、实证贡献、实践贡献分别阐述
- **创新性**：首次将情感即信息理论和目标-手段替代理论应用于开源研究
